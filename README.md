# Scoop Bucket

Personal Scoop bucket by [Omar Valdez](https://github.com/soyomarvaldezg).

## Available

### mocksmith

Generate realistic fake data for testing, demos, and data engineering pipelines.

```powershell
scoop bucket add soyomarvaldezg https://github.com/soyomarvaldezg/scoop-bucket
scoop install soyomarvaldezg/mocksmith
```

More tools will be added here as they are released.
